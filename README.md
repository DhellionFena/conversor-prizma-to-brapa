# 🎵 Conversor Prizma to BRAPA!

_Converta arquivos oto.ini do formato PRIZMA para BRAPA de forma rápida e eficiente!_

## 📌 Sobre o Projeto

Este conversor facilita a transição de oto.ini do método _PRIZMA_ para o formato _BRAPA_, permitindo que bancos de voz UTAU gravados na conotação _PRIZMA_ aproveitem os recursos do **OpenUTAU** e do **phonemizer.dll** desenvolvido pelo [**Team-BRAPA**](https://github.com/Team-BRAPA).

## 🎤 O que são UTAU e OpenUTAU?

- [**UTAU**](https://utau2008.xrea.jp/) é um sintetizador de voz popular que permite a criação de bancos de voz personalizados para cantar em diversos idiomas.
- [**OpenUTAU**](https://www.openutau.com/) é seu sucessor moderno, trazendo suporte aprimorado e novas funcionalidades para facilitar o uso e edição dos bancos de voz.

## 🔄 PRIZMA x BRAPA

Tanto _PRIZMA_ quanto _BRAPA_ são reclists (listas de gravação) usadas para criar bancos de voz com fonemas em português.

- [**PRIZMA**](https://youtu.be/IAOiuI9D4vU?list=PLBlbvJEBQrt1cyEdbdLgtsSbcR9TJ2JtS) foi criado por [**qkir0n**](https://www.youtube.com/@qkir0n) para o UTAU clássico.
- [**BRAPA**](https://github.com/Team-BRAPA/BRAPA), desenvolvido pelo [**Team-BRAPA**](https://github.com/Team-BRAPA), oferece suporte nativo ao OpenUTAU, aproveitando o phonemizer.dll para facilitar o uso e compatibilidade.

## 🚀 Como Usar?

1. Configure o ambiente:

   - Execute `setup_environment.bat` para instalar as dependências.

2. Converta os arquivos:

   - Execute `run_prizma_to_brapa.bat` para realizar a conversão dos oto.ini.

3. Acesse os arquivos convertidos:

   - Os novos oto.ini serão salvos na pasta **output/**.
